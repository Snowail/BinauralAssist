使用说明与理论

Detailed guide
为什么所有处理都必须 stereo-linked？

HRTF 的左右/前后线索全部藏在 L/R 的差异里：ITD（双耳时间差）、ILD（双耳电平差）和耳廓频谱。任何逐声道独立的压缩、限幅或 AGC 都会改变这些差异，直接把声像压扁。本项目所有动态增益都由 max(|L|, |R|) 计算，再同时乘到两个声道。

脚步：向上压缩与侧向增强

脚步是低电平短瞬态。普通“调大音量”会同时放大枪声和环境噪声；这里只对低于 upward_threshold_db 的瞬态按比例抬升，并用 gate_db 挡住底噪。侧信号 L−R 的增益只改变 ILD，不改变 mid，也不引入时延，所以 ITD 保持不变。

枪声：动态高频与 lookahead 限幅

枪声刺耳感集中在 2.5–9 kHz。检测到高频瞬态后，在 1.5 ms 内衰减该频带，180 ms 释放；同时用立体声联动限幅器压住峰值。限幅器预读 lookahead 越大越能压住起音，但端到端延迟会线性增加。

接线与电平

优先使用主板蓝色 Line-In，而不是粉色 Mic-In：后者常见单声道，并且会启用降噪/AGC/波束成形，抹掉 L/R 差异。关闭 Windows 和 Realtek 的所有麦克风增强；最响枪声的输入峰值调到约 −12 ~ −6 dBFS。若 L/R corr 持续接近 +1，说明输入被单声道复制，方向增强无效。
